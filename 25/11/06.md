# 生成 AI について知っていること

プロダクト Alive の機能拡張にあたり
2022 年頃に使おうとしていた Completions API は以下のような感じでした。

```
POST https://api.openai.com/v1/completions
{
    "model": "text-davinci-002",
    "prompt": "日本の首都を教えて",
}
```

```
{
    "text": " ください。日本の首都は東京です。",
}
```

当時はリクエストの後に「？」をつけるなどして 意図した回答が来るように工夫していましたが、完全ではありませんでした。

# 生成 AI について知っていること

2023 年公開の Chat Completions API の出現によって、質疑応答形式の回答がされるようになりました。

```
POST https://api.openai.com/v1/chat/completions
{
    "model": "gpt-4-turbo",
    "messages": [
       {"role": "system", "content": "あなたは親切なアシスタントです。"},
       {"role": "user", "content": "日本の首都を教えて"}
  ]
}
```

```
"message": {
    "role": "assistant", "content": "日本の首都は東京です。"
}
```

# RAG、Agent、オーケストレーション

**RAG**（検索拡張）や **Agent**（自律的に動くサポート AI）は、
この Chat Completions API の **messages** に  
検索結果や実行指示などの「追加情報」を組み合わせて送信することで動作します。

つまり、質問だけではなく「参照データ」や「実行すべきタスク」を一緒に受け取り、それを踏まえて応答を生成します。

このように、**API へのデータの組み合わせ方や処理の流れ全体を設計する仕組み**が  
「オーケストレーション」と呼ばれています。

アーキテクチャ例）
[Azure OpenAI Service リファレンスアーキテクチャ](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/final/ja-jp/microsoft-brand/documents/mcaps-biz-find-new-value-on-azure-RW1eA4r.pdf)

# Copilot Studio とは

Copilot Studio は、Microsoft 365, Power Platform 環境で動作する
**エージェント（Copilot）を設計・構築・運用するためのプラットフォーム**

＜ エージェント作成ツールの本命！？ Copilot Studio の機能＞

- エージェント構築・公開
- オーケストレーション（検索拡張／ツール呼び出し）
- 1100+ コネクタで社内外データに接続
- Power Automate で業務フローを起動
- 企業向けガバナンス（DLP／監査／ガードレール）

[エージェントプラットフォーム 全体像](06-4.pdf)

# なぜ Copilot Stuido を使うべきなのか

### エージェントを企業の認証・セキュリティ基盤上で運用できるから

- 機密情報が社外に出ない（Microsoft 365 内で完結）
- アクセス制御・監査ログ・DLP ポリシーなどが設定可能
- 管理者が利用範囲や挙動を制御・監査できる
- Teams や Power Automate と安全に連携できる
- `利用者の権限でエージェントがデータを探すことができる`
